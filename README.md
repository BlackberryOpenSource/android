Blackberry Android OS
===========

Getting started
---------------

To get started with Android, you'll need to get familiar with [Source Control Tools](https://source.android.com/setup/develop).

To initialize your local repository using this trees, use a command like this:
```
repo init --depth=1 -u https://github.com/BlackberryOpenSource/android.git -b android-10.0.0_r47
```
Then to sync up:
```
repo sync
```
